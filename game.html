JavaScript Shooting Star Game

This game was developed while following the W3 Schools JavaScript tutorial. After completing the tutorial, I enhanced the game by adding a differently colored border, adding a background image and changing the game piece, adding a play again button, adding CSS and lengthing the minimum gap between the obstacles.

Use the SHOOT STAR button to soar high in the sky. How long can your star fly?
